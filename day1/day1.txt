What is a Database?
A database is an organized collection of data that is used to store, manage, and 
retrieve information efficiently.

2. SQL vs NoSQL
SQL is suitable for structured data and applications that require strong relationships 
and transactions, such as banking systems. NoSQL is suitable for flexible, large-scale, 
and rapidly changing data, such as social media or real-time applications.

3. What is MongoDB?
MongoDB is a NoSQL, document-oriented database management system that stores data in 
flexible, JSON-like documents.

Main Features
The main features of MongoDB are document-oriented storage, flexible schema, powerful 
querying, indexing, and horizontal scalability.

Advantages
Flexible structure
Easy to work with JSON-like data
Good for modern web applications
Scalable
Powerful query system

4. Installing MongoDB locally or using MongoDB Atlas
MongoDB can be installed locally on a computer, or we can use MongoDB Atlas, which 
is a cloud-based MongoDB service.

5. Connecting to MongoDB using mongosh
mongosh is the MongoDB Shell. It is a command-line interface used to connect to and 
interact with a MongoDB server.

MongoDB Data Types
.String
String is used to store text data.
.Number
Number is used to store numeric values.
.Boolean
Boolean stores either true or false.
.Date
Date is used to store date and time values.
.Array
An array stores multiple values in a single field.
.Object
An object stores related data as key-value pairs inside a document.
.Null
Null represents an empty, unknown, or intentionally missing value.
.ObjectId
ObjectId is a unique identifier commonly used for the _id field in MongoDB documents.
.Decimal128
Decimal128 is used when high precision is required for decimal values, especially 
financial data.

BSON vs JSON
JSON is a text-based data format, while BSON is a binary representation of JSON-like 
documents. MongoDB uses BSON internally because it supports additional data types such 
as ObjectId, Date, and Decimal128 and is efficient for storing and processing data.

Auto _id
നമ്മൾ document insert ചെയ്യുമ്പോൾ _id manually കൊടുക്കുന്നില്ലെങ്കിൽ MongoDB automatically 
unique _id generate ചെയ്യും.
If we do not provide an _id when inserting a document, MongoDB automatically generates 
a unique _id, usually using an ObjectId.

ObjectId Structure

ObjectId example:
68b123456789abcdef123456

ഇത് 24 hexadecimal characters ആണ്, internally 12 bytes.
ObjectId
   ↓
12 bytes
   ↓
First 4 bytes → Timestamp
Remaining     → Other unique information
ObjectId is a 12-byte identifier. Its first 4 bytes represent the timestamp when the 
ObjectId was generated, while the remaining bytes provide uniqueness.

Extracting Timestamp from ObjectId
We can use getTimestamp() on an ObjectId to extract the timestamp encoded in the 
ObjectId.
_id.getTimestamp()

What is a collection?
A collection is a group of MongoDB documents, similar to a table in a relational database.

3. What is a document?
A document is a record in MongoDB, stored as a BSON document.

4. What is _id?
_id is a unique identifier for each document in a MongoDB collection.
